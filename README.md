# Project-Scheduler

A Python-based tool for planning software projects, managing task dependencies, estimating durations, and analyzing project schedules.

## Overview

Project-Scheduler is designed to demonstrate how software project activities can be organized and scheduled. It focuses on task dependencies, estimated durations, and project planning concepts.

## Features

- Task definition and organization
- Task duration estimation
- Dependency tracking
- Project schedule visualization through console output
- Basic critical path analysis (planned)

## Objectives

- Apply project scheduling principles.
- Understand task dependencies.
- Organize activities in a logical sequence.
- Explore project duration estimation.
- Practice Python programming.
